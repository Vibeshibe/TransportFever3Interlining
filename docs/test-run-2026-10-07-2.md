precede loading completion; line-use start is not proof of physical boarding.

## Implications for implementation

Use **S1/S3, Wimborne stop 1 to Melksham stop 2**, as the first controlled
same-terminal case. Retain S2 for later platform-transfer testing; its shared
station names do not make its terminal directly interchangeable with S1/S3.
Any implementation must preserve boarding direction and planned alighting
occurrence. Person `87485` illustrates why even another vehicle on the same
line is not necessarily eligible.

The current instrumentation is sufficient to continue the native queue/vehicle
selection trace without another generic probe run. No boarding fix is active.
